App Icon Guidelines

Follow these guidelines to ensure consistent app icons across all platforms.

Icon Grid & Safe Zone

Icon Grid Illustration

Use the standard icon grid to ensure consistent proportions:

  • Base grid: 108 × 108 px
  • Safe zone: 100 × 100 px
  • Corner radius: 16 px
  • Maintain visual weight across all icons

Icon Sizes

Export icons in the following sizes for different platforms:

  • iOS: 1024×1024, 180×180, 120×120, 80×80, 60×60
  • Android: 512×512, 192×192, 144×144, 96×96, 72×72, 48×48
  • Web: 512×512, 256×256, 128×128, 64×64, 32×32, 16×16
  • Windows: 1240×1240, 620×620, 310×310, 150×150
  • macOS: 1024×1024, 512×512, 256×256, 128×128, 32×32, 16×16

Usage Guidelines

Do's

  • Use the provided app icons without modification
  • Maintain minimum clear space around icons
  • Use platform-specific icon formats
  • Ensure icons are recognizable at small sizes
  • Use adaptive icons for Android

Don'ts

  • Don't distort or stretch app icons
  • Don't change the colors of app icons
  • Don't add effects like shadows or glows
  • Don't use app icons as decorative elements
  • Don't place app icons on busy backgrounds
